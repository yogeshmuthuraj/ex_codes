# ex_codes

A collection of Ruby code examples.

## Files

- [neighbours.rb](neighbours.rb)
- [rows_to_vertical.rb](rows_to_vertical.rb)

## Exploring the examples

Install Ruby and check that it is available:

```sh
ruby --version
```

Read each script to understand its inputs and behavior before running it. From the repository directory, run an example with:

```sh
ruby neighbours.rb
# or
ruby rows_to_vertical.rb
```
